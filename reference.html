Reference Names

Every foundation, atom and component has one unique name. Use these names to ask for a page to be built — nothing else needs describing.

How to use

Names follow component/variant.

  • A bare name means the default form — card is the same as card/default.
  • Variant names are only unique inside their component, so always namespace them: hero/dark, not dark.
  • Foundations (colour, type, space, grid, radius, shadow) are the building blocks every component is made from. Atoms are reused inside molecules and sections — the built from line on each card shows the trail.
  • Click any name to copy it.
